# DGM Craft - Tam Komut Referansı (582 komut)

Bu liste konsol yardımından otomatik çekildi (`?` komutu); `plugin:komut` tekrarları yalın hale indirildi.
İznin olmayan komut çalışmaz: **Oyuncu** = oyuncu grubu kullanabilir, **Admin** = admin/OP gerekir.
Kısa rehber ve Türkçe takma adlar için `komutlar.md` dosyasına bak.
