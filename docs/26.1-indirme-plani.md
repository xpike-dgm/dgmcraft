## 2. Kritik Uyarılar

1. **Dünya geri dönüşsüz kaybolur** — Minecraft dünyaları ileriye dönük uyumludur,
   geriye değil. 26.1.2, 26.2'nin chunk'larını açmayı reddeder. Bu yüzden dünya
   **silinmez, taşınır** (proje silme yasağı): `world/` → `world-26.2-yedek/`.
2. **Görev eşyaları yeniden doğrulanmalı.** 16 görev `minecraft:fence` ve
   `minecraft:chain` yüzünden düşüyordu; `oak_fence` ve `copper_chain` ile
   değiştirilmişti. Bu iki eşyanın **26.1.2'de de var olduğu doğrulanmalı.**
3. **Eklentiler çalışma anında kırılabilir.** `api-version` yalnız kapıyı kontrol
   eder; eklenti 26.1'e karşı derlenmiş Paper API'sini çağırıp
   `NoSuchMethodError` verebilir. Bu yüzden **yükleme testi zorunlu.**
4. **Java sürümü.** 26.1.2 farklı bir Java isteyebilir. Portable JDK 25 kurulu;
   yükleme testinde sorun çıkarsa Java 21'e düşülür.

belgelendi ve düzeltildi.
